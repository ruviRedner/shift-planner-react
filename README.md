# סידור משמרות דו־שבועי

פרויקט Frontend בלבד שנבנה עם React, TypeScript ו־Vite.

## הרצה

```bash
npm install
npm run dev
```

Vite יציג בטרמינל כתובת מקומית, בדרך כלל `http://localhost:5173`.

## בניית גרסת Production

```bash
npm run build
```

הקבצים המוכנים ייווצרו בתיקייה `dist`.

## מה כבר קיים בפרויקט

- לוח לשבועיים, מראשון עד שבת.
- משמרות צהריים ולילה בימים ראשון עד חמישי, משמרת שישי־שבת ומשמרת לילה במוצ״ש.
- שיבוצים קבועים לפי יום ומשמרת, עם אפשרות להחלפה חד־פעמית.
- רשימת אנשי צוות שנשמרת לשימוש חוזר.
- בחירה של כמה אנשים לאותה משמרת.
- מעבר בין תקופות של 14 ימים בלי למחוק תקופות קודמות.
- העתקת השבוע הראשון לשבוע השני.
- שמירה אוטומטית ב־`localStorage`.
- תצוגת הדפסה מותאמת ל־A4 לרוחב.
- התאמה למסך מחשב ולטלפון.

## שיבוצים קבועים

פתחו את „שיבוצים קבועים בכל שבוע”, בחרו יום ומשמרת, סמנו אנשים ולחצו „שמור קביעות”. אפשר לבחור כמה אנשים ואפשר להגדיר לאותו אדם כמה משמרות בשבוע.

לחיצה על משמרת בלוח ושמירה משנות רק אותה בשבוע שנבחר. גם שמירה ללא אנשים נשמרת כשינוי חד־פעמי. הכפתור „חזור לשיבוץ הקבוע” מסיר את השינוי ומחזיר את הקביעות העדכנית.

בשמירת קביעות האנשים שנבחרו מתווספים למשמרת של אותו יום וסוג בכל התקופות, כולל קודמות, גם במשמרות עם שיבוץ ידני או במשמרות שרוקנו. אנשים שכבר שובצו נשמרים ללא כפילויות. לאחר השמירה אפשר לבצע החלפה חד־פעמית כרגיל; שמירת הקביעות שוב מוסיפה מחדש את הנבחרים לכל השבועות. לביטול קביעות מבטלים את כל הבחירות ושומרים; פעולה זו אינה מוחקת שמות שכבר נוספו לשיבוצים ידניים.

העתקת שבוע מעתיקה גם החלפות חד־פעמיות ומשמרות שהושארו ריקות; משמרות קבועות ממשיכות לעקוב אחר הקביעות. ביטול ההעתקה משחזר את המצב הקודם. ניקוי תקופה מרוקן אותה בלבד, בלי למחוק את הגדרות הקביעות.

## גיבוי, עומס וחוסר זמינות

- **הורד גיבוי** שומר קובץ JSON עם כל התקופות, אנשי הצוות, הקביעויות, ההערות וחוסר הזמינות.
- **שחזר מגיבוי** בודק את מבנה הקובץ ואת הקשרים בין הרשומות, מציג תקציר ומבקש אישור לפני החלפת הנתונים. גיבויים קודמים ללא חוסר זמינות נתמכים. מגבלת קובץ: 10MB.
- **סיכום עומס בתקופה המוצגת** מציג לכל אדם את מספר משמרות הצהריים, הלילה ושישי־שבת. מוצ״ש נכלל בלילות; שישי־שבת נספרת פעם אחת. הספירה כוללת קביעויות והחלפות בפועל.
- **חוסר זמינות וחופשות** מאפשר להגדיר טווח תאריכים כולל יום ההתחלה והסיום, עם הערה. ההתראות מופיעות בלוח ובחלון השיבוץ גם עבור קביעויות. שישי־שבת נבדקת מול שני הימים. ההתראה אינה מבטלת את השיבוץ ואפשר לשמור אותו במכוון.
- **בטל פעולה אחרונה** משחזר שיבוצים, קביעויות, אנשי צוות, הערות וחוסר זמינות; גם ניקוי תקופה ושחזור מגיבוי ניתנים לביטול. נשמרות עד 30 פעולות במהלך פתיחת הדף; רענון מאפס את היסטוריית הביטול. הקלדה רצופה באותה הערה היא פעולה אחת. ניווט בין תקופות אינו מוסיף פעולה להיסטוריה, וביטול מחזיר לתקופה שבה בוצעה העריכה.

## בדיקות

נדרש Node.js 24 ומעלה לבדיקות יחידה ב־TypeScript ללא שלב קומפילציה נפרד.

```bash
npm test
npm run build
npm run test:e2e
```

בדיקות הדפדפן רצות ב־Edge ללא חלון גלוי, עם שרת מקומי בפורט 4173 ונתוני בדיקה מבודדים. ניתן לבחור דפדפן Chromium מותקן באמצעות משתנה הסביבה `PLAYWRIGHT_CHANNEL`. הבדיקות מכסות החלפות, ביטול פעולות, הורדה ושחזור גיבוי, חוסר זמינות, נתונים פגומים, נייד ותצוגת הדפסה.

## מבנה הקוד ועקרונות SOLID

- `domain/planner.ts`: טיפוסים, תאריכים והגדרות המשמרות. ימי המשמרת, קטגוריית העומס, צבע ומשך מוגדרים במקום אחד; החישובים צורכים את ההגדרות בלי תנאים נפרדים לכל סוג משמרת (Open/Closed).
- `assignments.ts`, `domain/commands.ts`, `domain/insights.ts`: פונקציות טהורות לחוקי השיבוץ, פעולות וחישוב עומס והתנגשויות, ללא תלות ב־React או בדפדפן (Single Responsibility).
- `storage/codec.ts`: אימות גיבויים והמרת נתונים ישנים. `storage/repository.ts`: ממשק מצומצם `PlannerRepository` עם `load` ו־`save`, ומתאם ל־localStorage (Interface Segregation).
- `main.tsx` מזריק את מתאם השמירה לאפליקציה. ה־hooks תלויים בממשק ולא במימוש localStorage, ואפשר להחליף אותו במתאם אחר בעל אותו חוזה; הבדיקות משתמשות באחסון בזיכרון (Dependency Inversion ו־Liskov Substitution).
- `domain/history.ts` מנהל את היסטוריית הפעולות. `hooks/usePlannerStore.ts` מחבר אותה ל־React ולשמירה. `hooks/usePlannerController.ts` מתאם בין פעולות המשתמש לחוקי התחום.
- `components/`: רכיבי תצוגה נפרדים ללוח, חלון שיבוץ, גיבוי, חוסר זמינות וסיכום עומס, המקבלים נתונים ופונקציות דרך props.

היישום משתמש בקומפוזיציה ובממשקים קטנים; אין צורך בהיררכיית ירושה כדי ליישם את העקרונות האלה.

## שינוי סוגי המשמרות בקוד

ב־`src/domain/planner.ts` נמצאת הפונקציה `getShiftsForDay`, המבוססת על הגדרות `SHIFT_META`. שם מוגדרים הימים, הטקסטים, הצבעים וקטגוריות הספירה של המשמרות.

## חשוב לדעת

אין שרת ואין מסד נתונים. המידע נשמר רק בדפדפן שבו האתר נפתח. ניקוי נתוני האתר בדפדפן ימחק את הסידורים שנשמרו.

אם נתונים קיימים אינם ניתנים לקריאה, האפליקציה מציגה שגיאה ועוצרת שמירה אוטומטית כדי לא לדרוס אותם. אם השמירה נכשלת, למשל עקב מגבלת נפח, מופיעה הודעה להורדת גיבוי.
