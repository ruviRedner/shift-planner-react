# סידור משמרות דו־שבועי

פרויקט Frontend בלבד שנבנה עם React, TypeScript ו־Vite.

## הרצה

```bash
npm install
npm run dev
```

Vite יציג בטרמינל כתובת מקומית, בדרך כלל `http://localhost:5173`.

## בניית גרסת Production

```bash
npm run build
```

הקבצים המוכנים ייווצרו בתיקייה `dist`.

## מה כבר קיים בפרויקט

- לוח לשבועיים, מראשון עד שבת.
- משמרות צהריים ולילה בימים ראשון עד חמישי, משמרת שישי־שבת ומשמרת לילה במוצ״ש.
- שיבוצים קבועים לפי יום ומשמרת, עם אפשרות להחלפה חד־פעמית.
- רשימת אנשי צוות שנשמרת לשימוש חוזר.
- בחירה של כמה אנשים לאותה משמרת.
- מעבר בין תקופות של 14 ימים בלי למחוק תקופות קודמות.
- העתקת השבוע הראשון לשבוע השני.
- שמירה אוטומטית ב־`localStorage`.
- תצוגת הדפסה מותאמת ל־A4 לרוחב.
- התאמה למסך מחשב ולטלפון.

## שיבוצים קבועים

פתחו את „שיבוצים קבועים בכל שבוע”, בחרו יום ומשמרת, סמנו אנשים ולחצו „שמור קביעות”. אפשר לבחור כמה אנשים ואפשר להגדיר לאותו אדם כמה משמרות בשבוע.

לחיצה על משמרת בלוח ושמירה משנות רק אותה בשבוע שנבחר. גם שמירה ללא אנשים נשמרת כשינוי חד־פעמי. הכפתור „חזור לשיבוץ הקבוע” מסיר את השינוי ומחזיר את הקביעות העדכנית.

בשמירת קביעות האנשים שנבחרו מתווספים למשמרת של אותו יום וסוג בכל התקופות, כולל קודמות, גם במשמרות עם שיבוץ ידני או במשמרות שרוקנו. אנשים שכבר שובצו נשמרים ללא כפילויות. לאחר השמירה אפשר לבצע החלפה חד־פעמית כרגיל; שמירת הקביעות שוב מוסיפה מחדש את הנבחרים לכל השבועות. לביטול קביעות מבטלים את כל הבחירות ושומרים; פעולה זו אינה מוחקת שמות שכבר נוספו לשיבוצים ידניים.

העתקת שבוע מעתיקה גם החלפות חד־פעמיות ומשמרות שהושארו ריקות; משמרות קבועות ממשיכות לעקוב אחר הקביעות. ביטול ההעתקה משחזר את המצב הקודם. ניקוי תקופה מרוקן אותה בלבד, בלי למחוק את הגדרות הקביעות.

בדיקות מנגנון השיבוץ (Node.js 24 ומעלה): `node --test src/assignments.test.mjs`.

## שינוי סוגי המשמרות בקוד

ב־`src/App.tsx` נמצאת הפונקציה `getShiftsForDay`. שם אפשר להחליט אילו משמרות יוצגו בכל יום. הטקסטים והצבעים נמצאים באובייקט `SHIFT_META`.

## חשוב לדעת

אין שרת ואין מסד נתונים. המידע נשמר רק בדפדפן שבו האתר נפתח. ניקוי נתוני האתר בדפדפן ימחק את הסידורים שנשמרו.
